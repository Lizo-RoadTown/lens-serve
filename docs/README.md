# docs/

This repo documents its own build **as it happens** (documents-as-we-go — capture
before loss). What lives here:

- build notes / decisions / what this repo needed and what it is missing, recorded
  as the repo builds itself out.

The shared database standard lives in **lens-core** (`docs/schema/`). The Lens as a
whole is kept in the lens-core repo (`docs/decomposition/`, method in `skills/decomposition/`); this folder is
lens-serve's own record.
